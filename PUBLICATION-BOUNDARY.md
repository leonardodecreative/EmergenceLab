# Emergence Lab — Public Repository Boundary

**Status:** Active repository policy  
**Effective:** 24 September 2026

This repository is the public scientific record for Emergence Lab.

## Public scope

Material belongs here when it has been explicitly approved for public release and serves one or more of these purposes:

- historical provenance;
- preregistration;
- reproducibility;
- frozen experimental apparatus;
- published result data;
- diagnostics required to interpret a published result;
- manifests, hashes, and adjudications;
- public white-paper or research-brief material.

Historical failures and negative results remain part of the record when they are scientifically relevant.

## Private development scope

Active development does **not** enter this repository by default.

Keep private until separately approved for publication:

- Gamma-successor designs before publication approval;
- active RSMA architecture development;
- unpublished mechanisms or controller designs;
- speculative experiments and internal research notes;
- working white-paper drafts;
- implementation details not required to reproduce a published claim.

A private working artifact does not become public merely because it relates to an already public experiment.

## Publication rule

The default path is:

1. design and review privately;
2. freeze or otherwise identify the exact artifact being tested;
3. execute and review;
4. approve the scientific record for publication;
5. publish only the material needed for the approved historical/reproducibility record.

Public release is therefore an explicit research disposition, not an automatic by-product of development.

## Licensing boundary

The repository-level MIT License applies to material released in this repository under that license. Moving future development to a private workspace does not revoke permissions already granted for previously released MIT-licensed material.

## Current interpretation

The public repository is the laboratory record, not the entire live workshop.

That distinction is intended to preserve open scientific provenance without requiring every active architectural idea or unpublished implementation to be developed in public.


## Reading public-facing demonstrations

The V2 site and visual lab are exploratory interfaces, not independently validated experimental results. Their drawn node anatomy, scalar readouts, and example behavior are not substitutes for the structured canonical node model or the specific assumptions in frozen historical experiments.

Likewise, an archived working-revision document or historical code artifact should not automatically be treated as an endorsed current model. Existing public PDFs, experiment files, and repository history remain publicly discoverable unless separately handled; merely unlinking material from a website does **not** make it private. Review such artifacts for publication approval before directing new collaborators to them.

The canonical node has five structured coordinates, `X, Y, Z1, Z2, Θ`; Gamma and energy remain outside that tuple. Active RSMA and Gamma-successor work are not represented by this public demonstrator.
